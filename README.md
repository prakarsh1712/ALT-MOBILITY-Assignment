# 📊 Alt Mobility Data Analyst Assignment

This repository contains the completed data analysis assignment for the Data Analyst Intern role at **Alt Mobility**.

---

## 📁 Repository Contents

### 📂 `sql/`
Contains SQL scripts for each of the assignment tasks:

- `Task1.sql` – Order fulfillment and revenue trend analysis
- `task2.sql` – Customer behavior and repeat order insights
- `task3.sql` – Payment success/failure investigation
- `task4.sql` – Combined order + payment view
- `task5.py` – Cohort-based retention analysis

### 📊 `visualizations/`
- `customer_retention_heatmap.png` – Heatmap showing retention patterns across customer cohorts

### 📝 `summary_of_findings.md`
Concise insights and recommendations derived from the data.

---

## 🧠 Key Insights

- **High Payment Failures:** Over 66% of payments are `failed` or `pending`, indicating a need for payment system improvements.
- **Customer Loyalty:** Only 2–5% of customers return after the first month, with strong drop-offs after the initial order.
- **Revenue Trends:** Sales have increased steadily, especially from late 2024 to early 2025.
